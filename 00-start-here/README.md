# Start with the feature

Read feature-brief.md and contracts.md, then write your own explanation of one
allowed, one rejected, and one repeated request. These files are input artifacts,
not a generated implementation. No account or cloud resource is needed.

For the build-your-own route, run `node tools/create-practice.mjs <practice-folder>`
from the repository root. Use lifecycle-notes.template.md after your first spec.
Success means you can explain the behavior and identify the open design questions.
